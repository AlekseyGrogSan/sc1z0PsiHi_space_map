# 📐 Полное описание архитектуры и функционала проекта
## Сервис «Карта пространства» (ТТК)

---

## 1. Контекст и бизнес-цель
При посещении крупных гостиниц, выставочных комплексов, конференц-залов или торговых центров люди сталкиваются с проблемой «слепой» ориентации:
- Текстовые описания и разрозненные фотографии не дают пространственного понимания.
- Трудно сопоставить расположение стендов, залов регистрации, кафе и санузлов.
- Нет возможности заранее «пройти» маршрут от входа до нужного спикера или стенда.

**Решение проекта:**
Веб-сервис, позволяющий организаторам за несколько минут создать цифровую интерактивную карту помещения с привязанными 360-панорамами (снятыми на обычный смартфон), а посетителям — мгновенно открыть карту на мобильном устройстве и проложить пешеходный маршрут.

---

## 2. Ключевые роли и сценарии пользователей

### 2.1 Посетитель (Visitor)
- **Доступ**: Без авторизации, по публичной ссылке или QR-коду на площадке.
- **Интерфейс**: Максимально легкий мобильный веб-интерфейс (PWA / Responsive).
- **Сценарии**:
  1. Выбор этажа на плане здания.
  2. Поиск точки интереса (POI) по категориям: стенды, Wi-Fi зоны, туалеты, кофе-брейк, выходы.
  3. Построение маршрута между двумя точками с расчетом дистанции и времени.
  4. Виртуальный просмотр пути: переключение между точками панорам вдоль построенного маршрута.
  5. Просмотр 360-панорамы с поддержкой поворота пальцем или гироскопа телефона.

### 2.2 Организатор площадки (Organizer)
- **Доступ**: Авторизация по логину/паролю (JWT).
- **Сценарии**:
  1. Создание пространства (Space) и добавление этажей.
  2. Загрузка чертежа/схемы 2D-плана (автоматическая конвертация в тайлы и WebP).
  3. Разметка стендов, комнат и точек интереса (POI) прямо на 2D-плане.
  4. Загрузка готовых 360° фотографий или запуск пошаговой фотосъемки со смартфона (серия снимков с поворотом на месте).
  5. Привязка панорам к точкам на 2D-плане и связывание их между собой интерактивными стрелками-переходами (Hotspots).
  6. Редактирование пешеходного графа (где можно ходить, где лестницы и лифты).
  7. Публикация карты (изменения применяются «на лету» без изменения ссылки).

### 2.3 Системный администратор (Superadmin)
- **Доступ**: Полный доступ ко всем пространствам платформы.
- **Сценарии**:
  1. Мониторинг дискового пространства в MinIO и нагрузки на воркеры сшивки.
  2. Управление учетными записями организаторов и квотами на количество панорам/медиа.
  3. Блокировка/модерация опубликованных карт при нарушении правил.

## 4. Пайплайн обработки медиаданных (S3 Storage)

### 4.1 Бакеты
1. **`spaces-staging`**: Приватный временный бакет. Хранит серии кадров со смартфонов для алгоритма сшивки. Очищается автоматически через 24 часа.
2. **`spaces-public`**: Публичный бакет для готовых оптимизированных ассетов. Раздается через Nginx с долгим кэшированием (`immutable`).

### 4.2 Требования к скорости мобильной загрузки
Для того чтобы 360-панорама мгновенно открывалась в условиях нестабильного мобильного интернета в помещениях, используется **3-этапная загрузка**:
1. **BlurHash (0 мс)**: Текстовый хэш строки, отдающийся внутри JSON ответа эндпоинта панорамы. Клиент мгновенно рисует размытый фон.
2. **Preview WebP (50-100 мс)**: Облегченное изображение панорамы (1024×512 px, ~50 КБ), дающее пользователю возможность сразу начать вращение камеры.
3. **Multi-resolution Cubemap Tiles**: Нарезка 6 граней куба на квадратные тайлы 512×512 px. Клиент (Pannellum / Marzipano) загружает только те тайлы, которые попадают в поле зрения камеры (FOV).

## 5. Алгоритм индор-навигации (Пешеходный граф)
1. **Граф путей**:
   - Вершины (`nav_nodes`): коридоры, двери, точки у стендов, лестницы, эскалаторы, лифты. Каждая вершина может быть опционально связана с ID ближайшей панорамы.
   - Ребра (`nav_edges`): физические проходы с указанием расстояния в метрах и флага доступности для маломобильных граждан (`is_accessible`).
2. **Поиск пути**:
   - На бэкенде реализован алгоритм **A\*** (или двунаправленный Дейкстра).
   - При переходах между этажами граф связывается через специальные ребра типа `stairs` / `elevator` с повышенным штрафным весом.
3. **Ответ сервиса навигации**:
   - Набор 2D-полилиний для каждого этажа (отрисовка цветной линии на плане).
   - Список пошаговых инструкций («Пройдите 15 м прямо», «Поднимитесь на 2 этаж на лифте»).
   - Упорядоченная цепочка панорам вдоль пути для визуального предпросмотра маршрута.
